#  Word Guessing Game Using Python

This is a beginner-friendly Python mini project that simulates a secret word guessing game.

The program allows users to guess a hidden word within a limited number of attempts and provides feedback based on the correctness of the guess.

## Features
- Secret word guessing system
- Limited guess attempts
- Correct and wrong guess feedback
- Remaining chances display
- Menu-free simple gameplay

## Technologies Used
- Python

## Concepts Covered
- Loops
- Conditional Statements
- Variables
- User Input Handling
- Guessing Game Logic

## Game Rules
- The player has only 3 attempts to guess the secret word.
- If the guessed word matches the secret word, the player wins.
- If all attempts are used, the game ends.
